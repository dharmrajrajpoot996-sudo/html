What is Machine Learning?

Traditional Software

In traditional programming, human developers write explicit rules and algorithms. Data is fed into these static rules to generate outputs and results.

This approach fails when problems become too complex for humans to hand-craft exact logical steps, such as facial recognition or language translation.

The ML Approach

Machine Learning flips the paradigm. We feed both data and known correct outputs (labels) into the machine learning system during training.

The algorithm infers the statistical patterns and generates its own program (model), capable of making accurate predictions on unseen data.

Gradient Descent Optimization

Gradient Descent iteratively updates weight parameter vector by stepping opposite to the loss gradient:

θt+1 = θt - α ∇J(θt)
Learning Rate (α): Controls the step size along the gradient curve per iteration.
Stochastic & Mini-Batch: Computes gradients on random data subsets to accelerate training convergence.
Adaptive Optimizers: Adam and RMSprop dynamically scale learning rates based on historical gradient moments.
